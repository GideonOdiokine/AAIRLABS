# Context Screenshots

This folder mirrors the `context/screenshots/` convention from the `web-app` project. It is for **design references and spec visuals** used while building (e.g. mockups, annotated states).

No design mockups were provided for the AAIRLABS exercise, so this folder starts empty aside from this note. Drop reference images here if you sketch or receive any.

## Not the same as submission screenshots

The exercise requires a **`/screenshots` folder at the repo root** containing real device/emulator captures of the running app (PNG/JPG, full screen, no mockup frames), embedded in the root `README.md`. Those are graded artifacts and live at the repo root, **not** here. See the [Submission Requirements](../project-overview.md#submission-requirements) in the project overview.
